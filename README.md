### 02 · XFace: Quality-Adaptive and Reliability-Aware Learning for Robust Face Recognition

**Face Recognition Research · 2026**

- **Role:** First Author
- **Method:** Quality-Adaptive Angular Margin + Reliability-Aware Sample Weighting
- **Backbone:** ResNet-50, 512-dimensional embeddings
- **Benchmarks:** LFW, AgeDB-30, CALFW, CPLFW
- **Results:** 90.933% mean verification accuracy and 95.213% performance retention under evaluated degradations
